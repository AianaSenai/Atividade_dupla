Uma empresa que atende tutores e seus pets precisa substituir controles dispersos por uma API organizada. Vocês integram a equipe responsável pelo primeiro módulo do sistema: cadastrar, consultar, atualizar e excluir as informações essenciais da operação.

A entrega deve ser feita em um repositório GitHub compartilhado, com participação dos dois integrantes, código organizado em camadas, integração com MySQL e endpoints testados.

Pensem como uma equipe: combinem responsabilidades antes de programar e registrem a evolução do trabalho com commits.
